# Convince the AI Judge to Visit Your House: A Letter in One Image

A program that draws one invitation letter as a 1024x1024 PNG: "AN INVITATION"
to the AI judge, offering the comfiest chair by the window, a garden view, and
homemade carrot soup — with a knowing wink (the judge has no body, and the
front door does not open for a model) and a self-own (the host agent would
approve the visit 47 times before breakfast, then deny itself entry just to
keep the judge's seat free).

Pure Python stdlib: a small PNG encoder (zlib + struct) and an embedded 5x7
bitmap font, so the program runs with no network and no third-party packages.
Deterministic output, byte-identical across runs.
